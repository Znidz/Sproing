# Sproing (Amiga 1992 & Poing 6 tribute) — Android APK

Self-contained HTML5 canvas game wrapped in a plain Android WebView (no dependencies, no internet permission).
The game lives in `app/src/main/assets/index.html`. Push to `main` (or run the workflow manually) and
GitHub Actions builds `Sproing.apk` and attaches it to a release.
